BMDRM DNS is an authoritative DNS platform designed for speed and flexibility. You can manage standard records through the dashboard or API, and you can attach scripts to respond dynamically to DNS queries based on geolocation, load, or custom logic. This page explains how BMDRM DNS works and how to set up your first zone.

## Key features

<CardGroup cols={3}>
  <Card title="Authoritative DNS" icon="network-wired">
    Host your domain zones on BMDRM with fast propagation and high availability.
  </Card>

  <Card title="Scriptable responses" icon="code">

  </Card>

  <Card title="Low latency" icon="bolt">

  </Card>

  <Card title="Record types" icon="list">

  <Card title="API and CLI" icon="terminal">

## How it works

You create a DNS zone and delegate your domain to BMDRM name servers. Standard records are served directly from the edge. For dynamic behavior, you attach a script to a record or zone. When a query matches, the script executes and returns a computed answer, such as the closest origin IP or a failover response.

## Get started

<Steps>
  <Step title="Create a zone">
    In the BMDRM dashboard, go to **Products \> DNS** and click **Add zone**. Enter your domain name.
  </Step>
  <Step title="Delegate name servers">
    Update your domain registrar to use the BMDRM name servers listed in the zone details.
  </Step>
  <Step title="Add records">
    Create A, CNAME, MX, and other records. Set TTLs and optional scripting rules per record.
  </Step>
  <Step title="Test resolution">
    Use dig or nslookup to verify records are resolving correctly from multiple locations.
  </Step>
</Steps>

<Tip>
  Start with a test subdomain before migrating your production domain to confirm record behavior and script logic.
</Tip>
