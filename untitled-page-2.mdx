Your API key lets you programmatically manage your videos and create streaming sessions via the [BMDRM API](/api-reference).

You can find your API key at [Settings \> API Keys](https://dash.bunny.net/account/api-key).

![Api Key 1](/images/Api-Key-1.png "Api Key 1")

## Viewing your API key

Your API key is hidden by default. Click the eye icon to reveal it, or the copy icon to copy it to your clipboard.

![API Key Eye](/images/API-Key-Eye.png "API Key Eye")

## Revoking your API key

If your API key is compromised, click the refresh icon to generate a new one. You'll be asked to confirm before the key is reset.

![Revoke Api Key](/images/revoke-api-key.png "Revoke Api Key")

<Warning>
  Revoking your API key will disable the old key immediately. Any applications or scripts using the old key will stop working.
</Warning>

## Keep your API key safe

Your API key has full access to your account. Never share it publicly or commit it to version control.
